# Changelog

All notable user-visible changes to the Cloudbeaver TOS application package.

## 26.0.5-1 — 2026-11-11

### Added
- First release. Cloudbeaver (`dbeaver/cloudbeaver:26.0.5`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8060 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/cloudbeaverdocker/`.
